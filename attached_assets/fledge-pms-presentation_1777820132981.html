Korean Localisation
Auto-generates HTML product descriptions with Korean legal notices (원산지, 소재, 제조년월) and footwear care warnings. Meta titles, keywords, and short descriptions all in Korean.
Legal Notice SEO Meta HTML Desc
👟
Division-Aware Gender Mapping
Maps raw GENDER × ITEM_DIVISION to precise Magento values: "MEN" + "FW" → "MEN SHOES", "WOMEN" + "APP" → "WOMEN CLOTHING". Handles MEN/WOMEN/UNISEX/KIDS across all three divisions.
FW / APP / ACC MEN / WOMEN / KIDS
📏
Smart Size Resolution
SIZE_ID resolved via product-type lookup tables: Tops (S–XXL), Pants (XS–4XL), Socks (S/M). Footwear uses RETAIL_SIZE (mm) directly. SIZE_ID "0" and RETAIL_SIZE "FREE" map to "One Size".
Tops / Pants Socks / Footwear One Size
🔗
Category URL → ID Resolution
Extracts hyperlinks from Excel CATEGORY columns using openpyxl, strips the locale prefix (kr/ko-kr/), and queries MySQL url_rewrite (store_id=5) to resolve each URL to its Magento category ID.
Hyperlink Extract MySQL Lookup store_id=5
🛒
Google Shopping Auto-Fields
Generates google_shop_category ("Apparel & Accessories > Shoes/Clothing") and google_shop_product_type per gender/division combination. URL keys are auto-slugified from product name + SKU.
Shopping Feed URL Keys Meta Fields

GitHub Code Sync
Clones the full Magento codebase from GitHub every 30 minutes. Custom module files are instantly available locally — no SSH round-trip needed for the first read.
Auto-Sync 30m Local Clone Vendor-Safe
🔐
SSH Live File Read
When a file isn't in git, the engine SSHs directly into Magento Cloud and reads the exact PHP file at the error path — ensuring vendor overrides and environment-specific code are never missed.
SSH Fallback Exact Line Vendor Files
🔍
Magento Web Search
Searches StackExchange, Adobe Community, and Magento DevDocs for known solutions. Results are passed to Claude — not displayed raw — so only validated, relevant steps reach the developer.
StackExchange DevDocs Adobe Community
🧠
Claude AI Synthesis
Claude receives the error message, the actual PHP file content (centred on the error line), and web search results. It validates sources and synthesises a Magento-specific, step-by-step fix — not generic advice.
Claude API Source-Grounded No Hallucination
🛠️
Pattern-Based Code Fix
Regex engine detects the error class — undefined variable, undefined array key, type error, undefined method — and generates the exact PHP initialisation or guard clause centred on the real error line.
Undefined Var Array Key Type Errors
🚦
Intelligent Priority Classification
Each log entry is scored P1 (fatal / uncaught exception), P2 (warning / cron failure / deprecation in critical path), or P3 (notice / info). The dashboard sorts by priority across both environments simultaneously.
